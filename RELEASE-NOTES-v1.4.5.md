# OmniHub Portal v1.4.5

- Keeps a generated quotation PDF available for ten minutes instead of revoking it immediately.
- Attempts the normal browser download and also displays a persistent **Download PDF now** button for browsers or WebViews that block automatic downloads.
- Cache-busts the Windows POS link to the management suite so the corrected portal is loaded after release.
- Continues to retain only the quotation reference and structured data; the generated PDF is not stored by OmniHub.
