# OmniHub Portal v2.7.2

The manager and administrator portal now contains a prominent **Sales & Delete Controls** page.

- Filter active sales and expenses by date.
- Select one or several rows or select all shown.
- Delete selected sales, selected expenses, or all selected rows.
- Delete every matching sale and/or expense using an exact confirmation phrase.
- Restore stock for deleted sales.
- Remove deleted records from operational totals while preserving protected audit evidence.
- Continue recording previous-day and custom-price sales.

All deletion actions are branch-scoped and limited to active manager or administrator profiles.
