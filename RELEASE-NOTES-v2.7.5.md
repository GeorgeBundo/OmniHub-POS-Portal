# OmniHub Portal v2.7.5

- Management-sale checkout now asks whether to open printer selection or complete without printing.
- The cashier or manager chooses A4 portrait, A5 portrait, 58 mm thermal, or 80 mm thermal before submitting the transaction.
- Browser printing opens the operating system print dialog so the actual installed printer can be selected.
- The printable receipt includes the configured OmniHub logo and receipt information.
- A blocked printer window is detected before the transaction is committed.
- Printing remains separate from the secure sale commit, so a printer failure cannot lose or duplicate a sale.
